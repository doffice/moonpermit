## 3. Verify a fresh registry consumer

Create a temporary module outside this checkout, then run:

```bash
moon new moonpermit-consumer
cd moonpermit-consumer
moon add doffice/moonpermit@0.2.0
```

In its executable package's `moon.pkg`, import the published library:

```moonbit
import {
  "doffice/moonpermit",
}

pkgtype(kind: "executable")
```

Replace that executable's `main.mbt` with:

```mbt nocheck
///|
fn main raise {
  let effect = @moonpermit.SecretRead("demo-token")
  let permit = @moonpermit.compile_plan("parent", [
    @moonpermit.effect_request(effect, @moonpermit.budget(max_calls=2)),
  ])
  let runtime = @moonpermit.runtime(permit)
  ignore(runtime.delegate("child", [
    @moonpermit.effect_request(effect, @moonpermit.budget(max_calls=1)),
  ], 0L))
  let receipt = runtime.check("parent-read", effect, 1L)
  let audit = @moonpermit.audit_events(permit, runtime.events())
  guard receipt.allowed() && receipt.remaining_calls == Some(0) &&
    audit.passed() && audit.checked() == 2 else {
    raise Failure("published delegation/audit integration failed")
  }
  println("registry-consumer: ok")
}
```

Run `moon check --deny-warn`, `moon build` and `moon run cmd/main` in the
consumer module. The expected final line is `registry-consumer: ok`.
Record the resolved dependency version and verification output.
